# 모듈 3: 엑셀 생성

검토를 마친 이슈를 영업 담당자가 바로 열어볼 수 있는 팀별 엑셀로 만든다.

- **팀별 시트** · `신규법인`, `1팀`~`6팀`으로 담당 법인만 모아 보기
- **최신순 정렬** · 최근 이슈가 있는 법인과 기사가 위로
- **바로 쓰는 서식** · 헤더 고정, 자동 필터, 원문 하이퍼링크, 요약 자동 줄바꿈
- **기간 통합** · 주말·연휴치는 `이슈트래커(260919~260920).xlsx`처럼 한 파일로
- **웹 다운로드** · GitHub Actions에서 날짜만 넣으면 엑셀 생성·다운로드

## 언제 실행되나

평소에는 [LLM 검토](../module2_news_pipeline/llm_review/README.md) 워크플로의 publish 단계가 검토를 마친 `issues_<날짜>.json`으로 자동 실행한다. 연휴 다음 첫 영업일에는 합본 엑셀도 함께 만든다. 아래 명령이나 **이슈트래커 엑셀 생성** 워크플로는 날짜를 지정해 다시 만들 때 쓴다.

검토가 끝나지 않은 날짜(`llm_review_result_<날짜>.json`이 없는 날짜)로 만들면 판정 전 항목이 빠진 엑셀이 나온다. `issues_<날짜>.json`의 `coverage_warnings`(수집 누락 가능성)는 엑셀에 표시되지 않는다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```bash
python3 -m pip install -r module3_excel_generator/requirements.txt
python3 module3_excel_generator/generate_excel.py --date 2026-09-17
```

| 구분 | 경로 |
|---|---|
| 입력 | `module2_news_pipeline/output/2026년 9월/issues_2026-09-17.json` |
| 출력 | `outputs/2026년 9월/이슈트래커(260917).xlsx` |

`--date`는 입력 파일을 선택하는 날짜다. 입력은 `--issues-dir` 밑에서 그 날짜가 속한 "YYYY년 M월" 폴더를 자동으로 찾는다(모듈 2가 쓰는 것과 같은 규칙). 출력 파일명은 입력 JSON의 `run_date`에서 만든다: `run_date`가 "2026-09-17"이면 `이슈트래커(260917).xlsx`, 주말·연휴처럼 여러 날짜를 하나로 묶어 `run_date`를 "2026-09-19~2026-09-20"으로 적어두면 `이슈트래커(260919~260920).xlsx`가 된다. 시트에 표시하는 기준일자도 같은 `run_date` 값을 쓴다. 합본은 `--date 2026-09-19~2026-09-20`처럼 기간으로 지정하며, 첫 날짜가 속한 월 폴더에서 `issues_2026-09-19~2026-09-20.json`을 찾는다. 입력 또는 출력 폴더를 바꾸려면 `--issues-dir`, `--output-dir` 옵션을 사용한다.

> **주의:** 같은 날짜(범위)의 엑셀이 이미 있으면 덮어쓴다. 검토를 마친 최종 엑셀은 저장소에 커밋해 이력을 남긴다.

## GitHub Actions로 생성

엑셀은 GitHub Actions에서 만들어 저장소에 바로 커밋할 수 있다.

1. GitHub 저장소의 **Actions** 탭에서 **이슈트래커 엑셀 생성**을 선택한다.
2. **Run workflow**를 누르고 생성할 기준일을 `YYYY-MM-DD` 형식으로 입력한다. 합본은 `YYYY-MM-DD~YYYY-MM-DD`로 입력한다.
3. 실행이 끝나면 워크플로우가 main의 `outputs/<YYYY년 M월>/이슈트래커(<기준일>).xlsx`에 엑셀을 커밋한다. 저장소에서 그 파일을 열어 **Download raw file**로 내려받는다.

같은 기준일로 다시 실행하면 기존 엑셀을 덮어쓴 커밋이 새로 생긴다. 입력할 날짜의 이슈 JSON이 main에 없으면 워크플로우는 실패한다.

## 생성되는 엑셀

| 항목 | 결과 |
|---|---|
| 시트 순서 | 신규법인, 1팀, 2팀, 3팀, 4팀, 5팀, 6팀 |
| 1행 | 기준일자 |
| 2행 | 법인명 / 키워드 / 영업시그널 카테고리 / 이슈요약 / 원문링크 |
| 법인 순서 | 가장 최근 기사 발행일 기준 내림차순 |
| 기사 순서 | 같은 법인 안에서 발행일 내림차순 |
| 여러 팀 소속 법인 | 해당하는 모든 팀 시트에 표시 |
| 기사가 없는 시트 | `해당 없음` 표시 |
| 탐색 기능 | 상단 2행 고정, 자동 필터, 원문 하이퍼링크 |
| 본문 | 10pt, 요약 셀은 자동 줄바꿈 |

`corp_status`가 `신규`인 법인은 신규법인 시트에 들어간다. 나머지 법인은 `team` 목록에 따라 팀별 시트에 배치한다. 키워드는 `matched_keywords`, 영업시그널 카테고리는 `keyword_tag` 값을 사용한다.
