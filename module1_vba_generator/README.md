# 모듈 1: VBA 코드 생성

업무망 엑셀의 팀별 법인 리스트에서 법인명과 담당 팀을 뽑아내는 VBA 매크로를 자동으로 만든다. 매크로를 한 번 실행하면 뉴스 수집의 기준이 되는 팀별 법인 목록이 즉시 창에 텍스트로 나온다.

- **설정 기반 생성** · 시트, 열 범위, 추출 조건을 `config.json` 하나로 관리
- **거래 법인 자동 판별** · 거래 확인 범위에 실적이 있는 법인만 추출
- **복사하기 쉬운 출력** · 팀당 한 줄(`1팀 (N건) - 법인A, 법인B, ...`)로 즉시 창에 출력

## 언제 실행하나요?

법인 리스트가 바뀌었거나 원본 Excel 구조가 변경됐을 때 실행한다. 평소 뉴스 수집과 엑셀 생성 과정에서는 다시 실행할 필요가 없다.

## 실행

저장소 루트에서 다음 명령을 실행한다.

```bash
python3 module1_vba_generator/generate_vba.py
```

기본 결과는 `module1_vba_generator/output/ExtractCompaniesByTeam.bas`다. 다른 설정이나 경로가 필요하면 `--config`, `--template`, `--output` 옵션을 사용한다.

## 업무망에서 법인 목록 뽑기

1. 생성된 `.bas` 파일을 조직의 승인된 파일 전송 절차로 업무망에 옮긴다.
2. 팀별 법인 리스트 Excel 파일을 열고 `Alt+F11`을 누른다.
3. VBA 편집기에서 `Import File...`로 `.bas` 파일을 불러온다. 표준 모듈에 코드를 직접 붙여넣어도 된다.
4. `ExtractCompaniesByTeamToFile` 매크로를 실행한다.
5. `Ctrl+G`로 즉시 창을 열어 팀별 목록을 복사한다.
6. 복사한 텍스트를 인터넷망으로 옮겨 [법인·팀 매핑 갱신 절차](../data/corp_team_mapping/README.md)에 따라 CSV로 정리하고 교체한다.
